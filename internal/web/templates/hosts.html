Query syntax and examples

Compare with == and !=, match a pattern with =~ and !~ (Go regular expressions, unanchored: add ^ or $ to anchor), and order numbers and versions with < <= > >=. Join conditions with && and ||, negate with !, and group with parentheses. Text goes in double quotes; true, false and numbers do not.

A name is an attribute such as os.version, or one of name, stack, role and application. A collector that takes a path or a name is written with it in brackets, file.exists["/etc/hosts"], or as file.exists == "/etc/hosts". has(os.version) is true when there is a value. Text without any of these symbols searches host names.
