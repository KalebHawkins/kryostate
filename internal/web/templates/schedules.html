Schedules

When each collector runs on its own, soonest first. Collectors that start within {{.Window}} of each other share a line down the left, amber when the slot is busy. Times are the server's ({{.Location}}).

{{if not .Scheduling}}
Scheduling is off in this server (it was started with -no-schedule). Schedules can still be set here; they take effect in a server that runs them.
{{end}}

Collectors run on many hosts at once, but never more than {{.MaxSessions}} sessions across the estate and {{.PerHost}} per host; anything more waits its turn. Collectors due in the same minute share one session per host.

Hosts are also spread over up to {{.Spread}} at random, and a host that cannot be reached is left alone for {{.Backoff}}, doubling each time up to {{.BackoffMax}}. Nothing runs more often than every {{.MinEvery}}. A schedule without a time of day gets one picked from the collector's name, so defaults do not all run together.

Next 24 hours runs starting each hour{{if .Measured}}; a session takes about {{.Session}}{{end}}
