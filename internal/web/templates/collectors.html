Collectors

A collector is a command hearsay runs on a host to read one value, such as the operating system version. This page lists every collector that will run.

Add your own

{{if .Mine}}

Your collectors are read from {{.Config.Collectors}}. Edit that file, then test a change before collecting:

{{else}}

You have no collectors of your own yet. Three steps:

{{end}}
    {{if not .Mine}}
  1. Create a starter file with one working example:
    hearsay collectors -init
    It is written to {{if .WantPath}}{{.WantPath}}{{else}}collectors.json next to the database{{end}}, where every command finds it.
    2. {{end}}
  2. Test it against one host. Nothing is saved:
    hearsay collectors -try <id> -host <host name>
  3. Collect for real:
    hearsay refresh
    {{if not .Mine}}Restart hearsay serve afterwards so this page and its Collect button use the new file.{{end}}

Read the step-by-step guide

Collectors are edited in a file, not on this page. A collector is a command that runs on every host, and this web page has no login of its own, so it must not be able to change one.
